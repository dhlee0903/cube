# cube

브라우저에서 돌리는 큐브. 2×2부터 7×7까지 된다.

- 큐브 면을 끌면 그 줄이 돌고, 큐브 바깥을 끌면 큐브 전체가 돈다
- 섞기, 힌트, 맞추기
- 타이머: 섞은 뒤 처음 조각을 잡을 때 시작해서 다 맞추면 선다. 크기별 최고 기록을
  남기는데, 힌트를 봤거나 맞추기 단추로 끝낸 판은 치지 않는다
- 테마 스물두 가지. 테마 하나가 장면 하나다. 큐브의 모양(모서리, 스티커 크기·두께), 겉면 질감,
  조명, 돌아가는 맛, 배경, 떠다니는 것, 돌릴 때 튀는 것이 테마마다 다르다

  | 테마 | 장면 |
  |---|---|
  | 기본 | 진열대 위 새 큐브. 도톰한 비닐 스티커, 딸깍 맞물리는 손맛 |
  | 네온 | 벽돌담의 네온사인. 고르면 칸마다 지직거리다 켜진다 |
  | 용암 | 굳어 가는 용암 덩어리. 아래서 붉은 빛, 몸통 틈새로 빛이 새고, 돌리면 달아오른다 |
  | 물 | 물속의 젤리. 빛줄기가 내리고 미끄러지듯 돌며, 돌리면 거품이 솟는다 |
  | 숲 | 그루터기 위 나무 블록. 이끼 방석, 흘러가는 햇빛 조각, 반딧불과 낙엽 |
  | 노을 | 해 지는 바닷가. 옆에서 낮게 드는 햇빛, 법랑에 비친 수평선, 지나가는 새 |
  | 우주 | 우주 정거장. 선체 판과 표시등, 성운이 비치는 창, 해 하나만 세게 |
  | 사탕 | 사탕 가게. 볼록한 알사탕, 줄무늬 몸통, 통통 튀는 회전 |
  | 사막 | 신전의 돌 블록. 면마다 다른 그림(해, 눈, 물결, 피라미드, 앙크, 깃털)이 새겨진 바랜 타일 |
  | 얼음 | 눈밭 위 얼음 조각. 얼음 속에 갇힌 색, 가장자리부터 끼는 성에, 눈송이 |
  | 금속 | 정밀 가공 부품. 동심원 결 알루마이트 캡, 나사 박힌 몸통, 기계처럼 탁탁 |
  | 종이 | 모눈종이 위 종이 공작. 골판지에 찢어 붙인 색종이와 그 그림자 |
  | 전기 | 테슬라 코일 실험실. 기어다니는 번개, 가끔 방 전체가 번쩍 |
  | 살점 | 아직 살아 있는 생고기. 울퉁불퉁 실제로 솟은 혹, 핏줄, 고름 주머니, 멍과 마블링. 심장처럼 뛰고 움찔하며, 파리가 꼬이고 피가 맺혀 떨어진다 |
  | 크툴루 | 심해의 것. 칸마다 실제로 솟은 눈알(하나 또는 셋)이나 촉수 빨판. 홍채와 세로 동공이 구면 위를 굴러 보는 사람이나 손끝을 쳐다보고, 이따금 휙 시선을 옮기며, 잡으면 일제히 질끈 감는다 |
  | 보석 | 벨벳 위 보석함. 금판에 솟은 원석, 면마다 갈라지는 빛과 무지갯빛 |
  | 글리치 | 고장 난 CRT. 주사선, 어긋나는 색, 버벅이는 회전, 가끔 화면째 튄다 |
  | 픽셀 | 8비트 게임. 면마다 다른 타일(벽돌, 돌, 구름, 물음표, 풀, 물), 칸칸이 끊기는 움직임 |
  | 회로 | 마더보드. 배선과 패드, 깜빡이는 LED, 돌리면 몰려가는 전류 |
  | 오로라 | 북극의 밤. 산 너머 오로라, 그 빛이 비치는 큐브, 조용히 내리는 눈 |
  | 대리석 | 미술관 받침대. 흰 대리석에 색 돌을 박고 금테, 위에서 핀 조명, 묵직하게 |
  | 호박 | 할로윈 밤. 달과 앙상한 나무, 박쥐, 칸마다 표정이 다른 호박등 |

- 다 맞추면 큐브가 한 번 번쩍이며 부풀고 크게 터진다. 기기에서 '동작 줄이기'를 켜 두면
  움직이는 효과는 끈다

크기, 색, 최고 기록은 브라우저에 기억해 둔다.

## 실행

```sh
npm install
npm run dev
```

```sh
npm test        # 큐브 상태 계산 테스트
npm run build   # dist/
```

`main`에 올라가면 GitHub Actions가 Pages로 배포한다. 처음 한 번은 저장소
Settings → Pages → Source를 **GitHub Actions**로 바꿔 줘야 한다.

## 구조

- `src/cube.js` 조각 위치와 방향만 다루는 상태. three.js와 떼어 놓아서 node로 바로 테스트한다
- `src/view.js` three.js로 그리기, 끌어서 돌리기. 조각은 InstancedMesh로 몇 번에 나눠 그린다.
  기기가 버거워하면 내부 해상도를 스스로 낮춘다
- `src/surfaces.js` 테마별 겉면 질감(셰이더 조각)
- `src/particles.js` 떠다니는 입자, 튀는 입자
- `src/motions.js` 테마별로 돌아가는 맛(곡선과 시간)
- `src/main.js` 단추, 기록, 타이머 표시
- `src/timer.js` 타이머
- `src/themes.js` 테마. 한 테마 안의 색이 서로 헷갈리지 않는지는 테스트가 본다

## 맞추기와 힌트

맞춘 상태부터 돌린 것을 전부 기록해 두었다가 거꾸로 되돌린다. 같은 축으로 이어진
회전은 한 번에 합치고, 서로 지워지는 것은 뺀다. 최단 수를 찾는 솔버는 아니다.
중간에 손으로 다 맞추면 기록은 비워진다.

힌트는 그 되돌리는 길의 다음 한 수를 보여 준다. 돌릴 층이 돌릴 방향으로 두 번
살짝 들썩인다.
