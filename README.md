# cube

브라우저에서 돌리는 큐브. 2×2부터 7×7까지 된다.

- 큐브 면을 끌면 그 줄이 돌고, 큐브 바깥을 끌면 큐브 전체가 돈다
- 섞기, 힌트, 맞추기
- 타이머: 섞은 뒤 처음 조각을 잡을 때 시작해서 다 맞추면 선다. 크기별 최고 기록을
  남기는데, 힌트를 봤거나 맞추기 단추로 끝낸 판은 치지 않는다
- 색 테마 스물두 가지. 테마마다 큐브 겉면 질감이 다르다
  - 네온: 스티커 가장자리를 따라 빛나는 관, 가끔 깜빡임
  - 용암: 흐르는 용암 위로 굳은 껍질이 떠다니고, 몸통 틈새로 빛이 샌다
  - 물: 젤리 같은 스티커 위로 물빛 무늬가 일렁인다
  - 숲: 이끼 얼룩과 잎맥, 나뭇결 몸통
  - 노을: 비스듬한 면에 노을빛이 걸린다
  - 우주: 스티커마다 작은 성운과 반짝이는 별
  - 사탕: 빙글 도는 막대사탕 소용돌이
  - 사막: 모래알과 바람 물결, 사암 지층 몸통
  - 얼음: 가장자리부터 파고드는 성에, 반짝임
  - 금속: 한 방향으로 갈아 낸 결과 반사
  - 종이: 손으로 오린 가장자리, 가장자리에 고인 물감
  - 전기: 어두운 판 위를 기어다니는 번개, 몸통 모서리에서 튀는 전기
  - 살점: 근섬유 결, 마블링, 도드라진 핏줄, 젖은 겉. 큐브가 심장처럼 뛴다
  - 크툴루: 꿈틀거리는 점액 무늬, 몇 칸에는 두리번거리다 깜빡이는 눈
  - 보석: 면마다 기울기가 다르게 깎인 보석, 두드려 편 금 몸통
  - 글리치: 주사선, 어긋나는 색, 줄째 밀리는 칸. 큐브가 가끔 튄다
  - 픽셀: 8비트 게임 블록
  - 회로: 기판 배선을 따라 흐르는 빛
  - 오로라: 밤하늘 위로 너울거리는 오로라 커튼과 별
  - 대리석: 대리석 결, 금빛 결이 지나는 검은 대리석 몸통
  - 호박: 촛불이 일렁이는 작은 호박등
- 테마마다 큐브 둘레에 떠다니는 것(불씨, 거품, 반딧불, 별, 눈, 모래바람 등)이 있고,
  한 줄을 돌리면 그 줄에서 불꽃·물방울·나뭇잎 같은 것이 튄다. 다 맞추면 큐브가 한 번
  번쩍이며 부풀고 크게 터진다. 기기에서 '동작 줄이기'를 켜 두면 움직이는 효과는 끈다

크기, 색, 최고 기록은 브라우저에 기억해 둔다.

## 실행

```sh
npm install
npm run dev
```

```sh
npm test        # 큐브 상태 계산 테스트
npm run build   # dist/
```

`main`에 올라가면 GitHub Actions가 Pages로 배포한다. 처음 한 번은 저장소
Settings → Pages → Source를 **GitHub Actions**로 바꿔 줘야 한다.

## 구조

- `src/cube.js` 조각 위치와 방향만 다루는 상태. three.js와 떼어 놓아서 node로 바로 테스트한다
- `src/view.js` three.js로 그리기, 끌어서 돌리기. 조각은 InstancedMesh로 몇 번에 나눠 그린다
- `src/surfaces.js` 테마별 겉면 질감(셰이더 조각)
- `src/particles.js` 떠다니는 입자, 튀는 입자
- `src/main.js` 단추, 기록, 타이머 표시
- `src/timer.js` 타이머
- `src/themes.js` 테마. 한 테마 안의 색이 서로 헷갈리지 않는지는 테스트가 본다

## 맞추기와 힌트

맞춘 상태부터 돌린 것을 전부 기록해 두었다가 거꾸로 되돌린다. 같은 축으로 이어진
회전은 한 번에 합치고, 서로 지워지는 것은 뺀다. 최단 수를 찾는 솔버는 아니다.
중간에 손으로 다 맞추면 기록은 비워진다.

힌트는 그 되돌리는 길의 다음 한 수를 보여 준다. 돌릴 층이 돌릴 방향으로 두 번
살짝 들썩인다.
