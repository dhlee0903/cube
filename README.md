# cube

브라우저에서 돌리는 큐브. 2×2부터 7×7까지 된다.

- 큐브 면을 끌면 그 줄이 돌고, 큐브 바깥을 끌면 큐브 전체가 돈다
- 섞기, 힌트, 맞추기
- 타이머: 섞은 뒤 처음 조각을 잡을 때 시작해서 다 맞추면 선다. 크기별 최고 기록을
  남기는데, 힌트를 봤거나 맞추기 단추로 끝낸 판은 치지 않는다
- 테마 여든세 가지. 기본, 자연, 빛·불, 우주, 보석·광물, 공예·천, 문양, 동물, 금속·기계, 음악, 디지털·레트로, 기묘로 묶어 고른다. 테마 하나가 장면 하나다. 큐브의 모양(모서리, 스티커 크기·두께), 겉면 질감,
  조명, 돌아가는 맛, 배경, 떠다니는 것, 돌릴 때 튀는 것이 테마마다 다르다

  | 테마 | 장면 |
  |---|---|
  | 기본 | 진열대 위 새 큐브. 도톰한 비닐 스티커, 딸깍 맞물리는 손맛 |

  | 숲 | 그루터기 위 나무 블록. 이끼 방석, 흘러가는 햇빛 조각, 반딧불과 낙엽 |

  | 켈트 매듭 | 돌에 깊이 새긴 매듭. 위 띠는 솟아 넘어가고 아래 띠는 내려앉는다 |
  | 아즈텍 | 돌을 깎아 층층이 솟은 계단 피라미드, 벗겨진 안료 |
  | 페이즐리 | 가죽 공예. 칼로 긋고 눌러 새겨 도톰하게 솟은 페이즐리, 안티크 물감 |

- 다 맞추면 큐브가 한 번 번쩍이며 부풀고 크게 터진다. 기기에서 '동작 줄이기'를 켜 두면
  움직이는 효과는 끈다

크기, 색, 최고 기록은 브라우저에 기억해 둔다.

## 배포

Vercel에 올린다. 처음 한 번만 https://vercel.com/new 에서 이 저장소를 가져오면
(설정은 `vercel.json`에 있어서 건드릴 것이 없다) 그다음부터는 `main`에 올릴 때마다
배포되고, PR마다 미리보기 주소가 생긴다. 배포 전에 테스트가 먼저 돌고, 실패하면 배포하지 않는다.

GitHub Actions는 PR과 `main`에서 테스트와 빌드만 확인한다.

## 구조

- `src/cube.js` 조각 위치와 방향만 다루는 상태. three.js와 떼어 놓아서 node로 바로 테스트한다
- `src/view.js` three.js로 그리기, 끌어서 돌리기. 조각은 InstancedMesh로 몇 번에 나눠 그린다.
  기기가 버거워하면 내부 해상도를 스스로 낮춘다
- `src/surfaces.js` 테마별 겉면 질감(셰이더 조각)
- `src/particles.js` 떠다니는 입자, 튀는 입자
- `src/motions.js` 테마별로 돌아가는 맛(곡선과 시간)
- `src/main.js` 단추, 기록, 타이머 표시
- `src/timer.js` 타이머
- `src/themes.js` 테마. 한 테마 안의 색이 서로 헷갈리지 않는지는 테스트가 본다

## 맞추기와 힌트

맞춘 상태부터 돌린 것을 전부 기록해 두었다가 거꾸로 되돌린다. 같은 축으로 이어진
회전은 한 번에 합치고, 서로 지워지는 것은 뺀다. 최단 수를 찾는 솔버는 아니다.
중간에 손으로 다 맞추면 기록은 비워진다.

힌트는 그 되돌리는 길의 다음 한 수를 보여 준다. 돌릴 층이 돌릴 방향으로 두 번
살짝 들썩인다.
